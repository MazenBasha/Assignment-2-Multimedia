# Report

Final deliverable PDF lives here as `report.pdf`. Sources:

* `outline.md` — section-by-section structure (delete or fold into the PDF).
* `references.bib` — BibTeX for everything cited in the README + report.

Suggested workflow:
1. Draft prose in `outline.md`.
2. Embed numbers from `outputs/metrics_mode_a.json` and
   `outputs/metrics_mode_b.json` (the run script writes those).
3. Pull qualitative blocks from `outputs/qualitative_mode_a.md` and
   `outputs/qualitative_mode_b.md`.
4. Render to `report.pdf` (LaTeX or Markdown-to-PDF, your choice).
